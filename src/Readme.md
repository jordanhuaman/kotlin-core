# Kotlin
## Language Guide
### Functions
- The simples fn can be declared like this `fn():Int = return 2`. Interesting way to build a function.
### Variables
- We only have two options to declare a variable.
  - val: to declare variables that are assigned a value only once. **immutable** or **read-only**.
  - var:It can be resigned.
- Type inference
- Reassign variable
### Clases
- The default constructor is in the class declaration.
- By default, all the classes are **final**, so it can't be in inherited.
- We can use **open class Classname**.
- Kt doesn't multiple inheritance.
- The `:this` call another constructor of the class. If there are more than 3 constructor all the constructors calls the default constructor.
### Conditionals
- **if**, **for** and **while** conditional are the same another languages.
- The ***when*** statement is similar like ***switch***-java statement but more powerful.
- With ***Range*** statement we can iterate based to a progresion like ```1...10 or 10 downTo 0```
